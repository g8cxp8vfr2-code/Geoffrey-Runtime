# Welcome to Geoffrey Runtime

Installer menu for the Shortcut components presented as Geoffrey Runtime setup steps.

## Input

No explicit input is required.

## Observed menu

The installer offers entries for:

- Geoffrey home menu button
- Talk to Geoffrey
- Geoffrey Request Information
- Text Geoffrey
- From Geoffrey
- Notification app
- Set Geoffrey schedule
- Run Geoffrey Schedule
- Customer service
- Subcribe to Geoffrey Runtime

## Observed processing flow

Each menu branch opens the corresponding iCloud Shortcut-sharing URL.

For security, the installed URLs are not reproduced here. Every URL is represented by:

```text
<REDACTED_SHORTCUT_URL>
```

## Output

The selected iCloud Shortcut installation page.

## Failure conditions

- No menu selection is made.
- The selected URL cannot be opened.
- Network or iCloud Shortcut-sharing service access is unavailable.

## Security

Do not publish the installed share URLs. A distributed Shortcut may contain private authorization material; documentation must never make that material or its distribution URL public.
